## 1. The fork's wall, priced per row in the frame the cap is paid in

One binary, `taskset -c 0` (the graded frame is ~one core: the completed hidden
run's 635 s over 300 two-call rows ≈ 1.06 s/call, against 0.83 s/call locally
pinned to one core and 0.60 s/call at four), `SSI_MARK_NOSCORE=1`, production
seams, 30 rows chosen as the union of the corpus's heavy set and the fork band:

| arm | seams | 30-row wall |
|---|---|---|
| A fork ON, registration ON | — | **43.00 s** |
| B fork ON, registration OFF | `SSI_NO_CHAIN_DONOR=1` | 42.77 s |
| C fork OFF, registration ON | `SSI_NO_BASIN_FORK=1` | **37.64 s** |
| D fork OFF, registration OFF | both | 38.11 s |

* **the fork costs +5.36 s (A−C) / +4.66 s (B−D) over those 30 rows**, and the
  cost lands entirely on the fork band's *heaviest* rows: `chimera_mgw-c8-439-
  onc8-001` 0.771 → 1.529 s, `chimera_mgw-c8-439-onc8-002` 0.762 → 1.535 s,
  `rocket50` 0.771 → 1.529 s, `gancns` 0.767 → 1.466 s, `wastewater13m1`
  0.681 → 1.336 s, `tls6` 0.623 → 1.223 s — while the heavy rows *outside* the
  band (`arki0016`, `crudeoil_lee4_10`, `gams05`, `arki0013`) move by ≤ 0.07 s.
* **the registration costs +0.23 s (A−B) / −0.47 s (C−D)** over the same rows —
  i.e. nothing outside the ±0.06 s/row noise floor — while carrying the value
  (`crudeoil_pooling_dt3` 0.7056 → 0.6449, `arki0013` 0.3993 → 0.3919,
  `crudeoil_lee4_09` 0.6171 → 0.6100 with it on).
* the fork's whole *value* on that 30-row set is two rows: `chimera_mgw-c8-439-
  onc8-001` 0.7522 → 0.7347 and `gancns` 0.8421 → 0.8407 — the same rows that
  carry its wall cost.

Hidden, the fork is worth −7.8e-5 (bat `3587d1b` was rejected below the 1e-4
bar) while the registration is worth −1.57e-4 dev with the fork off. Retiring
the fork therefore buys ~0.7 s/row of cap margin on the class that is closest to
the line (in the harness frame a single 1.529 s row + sandbox/parse overhead is
what put `gasprod_sarawak16`-class rows at ≥ 2.0 s: `results.tsv` 1789347694).
